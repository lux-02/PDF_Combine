# 📄 PDF & Image Combiner

Adobe Acrobat처럼 여러 PDF와 이미지 파일을 하나로 병합하는 웹 애플리케이션입니다.

## ✨ 주요 기능

- 📁 **다양한 파일 형식 지원**: PDF, JPG, PNG, DOCX
- 🔄 **드래그 앤 드롭 정렬**: 직관적인 파일 순서 조정
- 🖼️ **실시간 썸네일 미리보기**: 병합 전 결과 확인
- 💾 **간편한 다운로드**: 병합된 PDF를 즉시 다운로드
- 🎨 **모던한 UI/UX**: 깔끔하고 사용하기 쉬운 인터페이스

## 🚀 사용 방법

1. PDF, 이미지 또는 Word 파일을 업로드합니다
2. 드래그하여 파일 순서를 조정합니다
3. 썸네일로 미리보기를 확인합니다
4. "PDF 병합 및 저장" 버튼을 클릭합니다
5. 병합된 PDF를 다운로드합니다

## 🛠️ 로컬 실행

```bash
# 의존성 설치
pip install -r requirements.txt

# 앱 실행
streamlit run app.py
```
